# JPEG XL (JXL) Converter PWA

JPEG、透過PNG、動画GIF、透過動画WebPをブラウザローカルで高品質な JPEG XL (`.jxl`) に変換する、完全オフライン対応の PWA Webアプリケーションです。

---

## 🌟 主な機能・特徴

1. **PWA (Progressive Web App) 対応**
   - ブラウザから「アプリとしてインストール」可能（デスクトップ・モバイル両対応）。
2. **完全ローカル＆オフライン動作**
   - Service Worker のキャッシュと WebAssembly (WASM) により、インターネット接続なし（オフライン）でも100%動作。
   - 画像データは外部サーバーに一切送信されず、すべてブラウザ内で安全に高速処理。
3. **多彩な画像フォーマットに対応**
   - **JPEG / JPG**
   - **透過PNG**（アルファチャンネル透過を完全維持）
   - **動画GIF**（全フレームのアニメーション・ディレイを維持）
   - **透過動画WebP**（アルファ透過とアニメーションを完全維持）
   - **JXL再圧縮**
4. **品質調整スライダー**
   - 1% 〜 100% までスライダーで直感的に調整可能。
   - **100% 設定時は「ロスレス（無劣化可逆圧縮）」** に自動切り替え。
5. **元ファイル名の維持**
   - 変換前のファイル名を引き継ぎ、拡張子のみ `.jxl` に変更して出力（例: `photo.png` → `photo.jxl`）。
6. **Exif メタデータの保持＆選択的更新**
   - 元画像の Exif メタデータ（カメラ情報、撮影設定、GPS等）を保持。
   - 更新日時（DateTime）を現在日時に、ExifVersion を最新に更新して JXL 内の `Exif` ボックスに埋め込み。
7. **快適な高速バックグラウンド処理 (Web Worker)**
   - 複数ファイルの一括ドロップ・並行変換に対応。
   - 画面がフリーズせず、リアルタイムに進捗状況を表示。
8. **一括ZIPダウンロード**
   - 変換完了した複数の JXL ファイルをワンクリックで ZIP にまとめて一括保存可能。

## 🚀 起動方法

### 方法 1: バッチファイルをダブルクリック
`start_server.bat` をダブルクリックするだけで、ローカルサーバーが起動しブラウザが自動的に開きます。

### 方法 2: コマンドラインから起動
```bash
# Node.js で起動
node server.js
```
起動後、ブラウザで [http://localhost:8080](http://localhost:8080) にアクセスします。

---

## 📱 PWA としてインストールする方法

1. Chrome または Edge で `http://localhost:8080` を開きます。
2. アドレスバーの右端にある **「インストール」アイコン**（または画面上部の「インストール」ボタン）をクリックします。
3. デスクトップアプリとして独立したウィンドウで起動・利用できるようになります。
